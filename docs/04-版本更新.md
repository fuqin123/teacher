## v0.4.0（2026-11-24）—— 数据库改为本地 SQLite

### 背景

v0.3.0 的部署形态是 PostgreSQL + API + Web 三容器。实际使用范围确定为“一位教师、一个班级”，成绩数据总量在万级以内，独立数据库容器对教师本机是额外负担：需要 Docker、需要维护数据库密码、备份要依赖 `pg_dump`。本版本把数据库收敛为一个 SQLite 文件，业务功能与接口行为不变。

### 变更

1. **数据存储**
   - `schema.prisma` 的 `provider` 由 `postgresql` 改为 `sqlite`；
   - 去掉 `@db.Decimal`、`@db.Date` 等 PostgreSQL 原生类型，分数继续使用 Prisma `Decimal` 标量；
   - 删除旧的 PostgreSQL 初始化迁移，重建 `init_sqlite` 迁移；
   - 数据库文件：开发为 `apps/api/data/scorelens.db`，容器内为 `/app/data/scorelens.db`。

2. **会话存储**
   - 移除 `connect-pg-simple`、`pg` 及对应类型包；
   - 新增 `apps/api/src/common/prisma-session.store.ts`，会话写入 `user_sessions` 表，重启服务后登录态保留；
   - 不再引入 `connect-sqlite3` / `better-sqlite3` 等原生 SQLite 驱动，避免教师机器上的编译依赖。

3. **脚本与运维**
   - 删除 `db:up` / `db:down`（不再有数据库容器）；
   - 新增 `db:reset`（重置并重新迁移）、`db:backup`（`VACUUM INTO` 一致性快照）；
   - 种子脚本的 `TRUNCATE ... CASCADE` 改为按外键顺序 `deleteMany` 事务。

4. **部署**
   - `docker-compose.yml` 去掉 `postgres` 服务与 `POSTGRES_PASSWORD`；
   - 数据库与上传文件共用 `app_data` 卷，备份快照通过绑定挂载直出到宿主机 `./backups`；
   - 根目录 `.env.example` 同步删除数据库密码项。

5. **查询适配**
   - 名单搜索移除 PostgreSQL 专属的 `mode: 'insensitive'`，依赖 SQLite `LIKE` 的默认行为。

### 验证

- `pnpm typecheck`、`pnpm build` 通过；`prisma migrate deploy` 在空目录下自动创建数据库与目录。
- 种子重建 42 名学生、3 场考试、630 条成绩。
- `/api/v1/health` 返回 `db=up`；登录、`/auth/me`、名单搜索、看板统计（Decimal 读取与聚合）、导入上传→映射→校验→入库全链路通过。
- 重启 API 后同一 Cookie 仍可访问 `/auth/me`，确认会话持久化。
- `pnpm db:backup` 生成一致性快照成功。

### 已知问题

- SQLite 为单写者模型，多人并发导入需要迁移到 PostgreSQL。
- Docker 镜像未在本版本内重新构建验证（编排改动已通过 `docker compose config` 校验），Ubuntu 实机验收仍按部署文档执行。
- 自动化测试仍未补齐。

## v0.3.0（2026-11-24）—— Ubuntu Docker 全栈部署

### 背景

v0.2.0 的部署文档依赖宿主机安装 Node.js、pnpm、PostgreSQL 和 Caddy，并手工维护 API 服务。为降低学校服务器安装与运维门槛，本版本将完整应用容器化，Ubuntu 24.04 只需 Docker Engine 和 Docker Compose 插件。

### 新增

1. **全栈 Docker Compose**
   - PostgreSQL 16、NestJS API、Vue Web/Caddy 三个服务；
   - API、Web 多阶段镜像与根目录 `.dockerignore`；
   - 数据库、上传文件和 Caddy 证书/配置使用持久化卷；
   - API 启动时自动执行 `prisma migrate deploy`。

2. **部署配置与可观测性**
   - 根目录 `.env.example` 统一管理数据库密码、Session 密钥、站点地址和端口；
   - API 健康检查同时验证进程与数据库；
   - Web 健康检查验证 Caddy 首页；
   - `COOKIE_SECURE` 可显式控制 Secure Cookie。

3. **Ubuntu 部署文档**
   - Docker 安装、环境变量、HTTPS、防火墙和验收清单；
   - 演示数据、备份恢复、升级回滚和故障排查；
   - 明确数据库与 API 端口不暴露公网。

### 变更

- `pnpm db:down` 改为只停止 PostgreSQL，避免误停整个应用栈。
- README、项目架构、功能清单和开发记录同步当前版本与部署基线。
- 界面版本角标更新为 `v0.3.0`。

### 修复

- Caddyfile 统一为 `caddy fmt` 可接受的缩进，消除启动格式警告。
- 上传文件恢复命令改为在 API 停止时使用一次性容器，避免 `docker compose exec` 无法执行。

### 验证

- `docker compose config --quiet`、`pnpm typecheck`、`pnpm build` 通过。
- API、Web 镜像构建成功，PostgreSQL、API、Web 三个容器健康检查通过。
- 自动迁移、Caddy 健康检查、登录会话、SPA 深层路由回退和上传目录写入通过本机 Docker 验证。
- Ubuntu 24.04 实机验收仍需按部署文档执行。

### 已知问题

- 自动化测试仍未补齐。
- Prisma 在 slim 镜像中可能输出 OpenSSL 检测警告；当前迁移和运行验证正常，后续继续做镜像加固。

## v0.2.0（2026-11-23）—— 下拉、留白与图表动效

### 背景

v0.1.0 使用原生 `<select>`，在不同浏览器中样式不一致；内容区最大宽度 1320px，在 1920px 屏幕上两侧留白偏大；ECharts 虽然配置了图表，但入场动画不明显。参考 `E:\teacher_class\app` 的 shadcn/ui Select / Combobox 方案与图表封装策略，在不引入额外 UI 依赖的前提下做本项目适配。

### 新增

1. **AppSelect 组件**（`apps/web/src/components/AppSelect.vue`）
   - 基于 Teleport 的 fixed 浮层，自动计算上下空间，弹层始终位于触发框外侧，不再遮挡按钮；
   - 弹层宽度与触发框对齐并支持最小宽度；
   - 可搜索；键盘 ↑ / ↓ / Enter / Esc 操作；选中项勾选高亮；滚动跟随；
   - 支持 `size="sm"`、禁用、提示文字（hint）、空状态；
   - 使用原型设计令牌与轻量缩放/淡入动画。

2. **学生快速定位**
   - 学生列表新增可搜索学生下拉，支持按姓名 / 学号 / 班级过滤，选中后直接进入学生档案。

3. **图表骨架与动画**
   - 柱状 900ms 逐柱生长（quarticOut，55ms/柱）；
   - 曲线 1200ms 绘制（cubicInOut）；
   - 雷达 1000ms 由中心外扩（cubicOut，180ms/序列）；
   - 多序列之间 90ms 错峰；数据切换 650ms 形变，而非整图重播；
   - 初始化期间显示骨架条，图表就绪后淡入；
   - 支持 `prefers-reduced-motion: reduce`。

### 变更

1. 内容区最大宽度 `1320px` → `1600px`，顶部栏与内容区左右内边距统一为 `24px`。
2. 顶栏考试 / 班级 / 科目，学生列表班级筛选，导入页班级 / 考试类型 / 列映射全部改用 AppSelect。
3. 版本号与界面角标更新为 `v0.2.0`。

### 修复

- ECharts 封装在 `setOption` 之后立即 `ResizeObserver.observe`，首次回调会触发 `resize()`，导致入场动画被直接压到终态。现改为尺寸判重（宽高变化 > 1px 才 resize），初始回调忽略。
- 图表数据切换原先使用默认合并，容易整图重播；现改为 `replaceMerge: ["series"]` 保留组件、只形变序列。

### 验证

- `pnpm typecheck`、`pnpm build` 通过。
- 浏览器验证：顶栏三类下拉、导入列映射搜索、学生快速定位、看板/学生档案图表入场动画、内容区宽度。
- 下拉浮层位于触发框下方 6px，宽度与触发框对齐；长列表可搜索过滤。
- 图表首次渲染可见逐柱 / 绘制 / 外扩过程；切换考试/班级/学生时为形变更新。

### 已知问题

- 图表入场动画期间缩放窗口会被一次 resize 直接对齐终态（优先保证尺寸正确）。
- AppSelect 当前为项目内轻量实现，未引入完整无障碍 roving tabindex；基础键盘操作与 aria 属性已具备。
- 自动化单测仍未补齐，当前以类型检查、构建与浏览器端到端验证为准。
