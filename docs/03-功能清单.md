> 文档版本：v0.2（讨论稿）
> 更新日期：2026-11-24
> 关联文档：[项目架构](./01-项目架构.md)｜[技术选型](./02-技术选型.md)

> **v0.6.0 已落地**：F-B01 / F-B02 / F-B03 / F-B06（基础数据维护）、F-D04 / F-D14（AI 表头映射与降级）、F-G02（AI 开关、接口地址、Key、模型、超时与连通性测试，管理员在界面配置）；另支持学校导出的多级表头成绩表（科目 × 分数/校名次/班名次）与标准 xlsx 模板下载（含总分与排名列）。

## 1. 说明

### 1.1 优先级

| 优先级 | 含义 |
| --- | --- |
| P0 | 首版必须具备，缺少则主链路不成立 |
| P1 | 完整体验与效率提升，第二阶段交付 |
| P2 | 增强功能，后续按需排期 |

### 1.2 角色缩写

| 缩写 | 角色 |
| --- | --- |
| 管 | 系统管理员 |
| 级 | 年级主任 |
| 班 | 班主任 |
| 科 | 任课老师 |

同一用户可拥有多个角色，功能权限取并集。

### 1.3 核心用户旅程

1. **班主任整班导入**：管理员建好学期/班级/学生 → 班主任上传整班成绩表，在向导中确认或创建考试记录 → 确认 AI/手动映射 → 修正异常 → 入库 → 查看本班看板与排名。
2. **班主任/年级主任单科导入**：选择已有考试和科目，上传单科表 → 校验 → 合并入库 → 查看本科成绩（任课老师默认只读）。
3. **年级主任对比**：考试入库完成后 → 打开年级对比 → 查看各班均分、学科偏差热力表 → 导出。
4. **历史回溯**：为过去学期建立班级组映射 → 用同一流水线导入 → 趋势按考试时间串联。

| F-B01 | 学期管理 | P0 | 管 | 创建学年+学期（如 2026-2027 第一学期）；同学年学期唯一；可设当前学期；有考试的学期不可删除 |
| F-B02 | 年级/班级管理 | P0 | 管 | 按学期建年级（初一/初二/初三）和班级；年级带入学届（entry_year）；班级设置班主任、排序并归属稳定的"班级组"；班级名在年级内唯一；有成绩的班级不可删除 |
| F-B03 | 学生档案 | P0 | 管（班只读） | 列表/搜索/筛选；学号唯一；新增/编辑姓名与状态；按学期归属班级；有成绩不可硬删除（可置为离校） |
| F-B04 | 学生名单导入 | P0 | 管 | 下载模板（学号/姓名/班级）；先预检后提交；学号重复、班级不存在、姓名缺失逐行报错；成功后建立学期归属；输出成功/失败统计 |
| F-B05 | 学生班级异动 | P1 | 管 | 转班/休学/复学；记录异动历史；不修改历史成绩的班级快照；新考试使用新班级 |
| F-B06 | 科目管理 | P0 | 管 | 预置文化科目；可新增/停用/排序；设置类别（文化/其他）与默认满分；有成绩的科目不可删除，只能停用；地理/生物若按会考组织，可停用或在该场考试中设为不计入总分 |
| F-B07 | 任课与年级主任配置 | P0 | 管 | 按学期配置任课（班级×科目）与年级主任；一个班级可多个科目老师；配置后立即影响数据范围；历史学期需有对应任课记录才能查看历史成绩 |
| F-B08 | 学期复制/升级 | P2 | 管 | 从上一学期复制班级、任课、学生归属；提供升级预览；不复制成绩 |
| F-B09 | 数据字典 | P1 | 管 | 考试类型、科目别名、缺考标记等可维护；修改需审计 |

| --- | --- | --- | --- | --- |
| F-C01 | 创建/确认考试记录 | P0 | 管、级、班（导入时） | 首版不要求预建考试：导入向导中确认学期/年级/名称/类型/日期，提交时按"学期+年级+名称"查找或创建；考试记录全年级共享，其他班复用；同年级同学期名称唯一；可归档 |

| F-C03 | 考试列表/筛选 | P0 | 管、级、班、科（只读） | 按学期/年级/类型筛选；展示考试状态、科目数、导入进度；归档考试不出现在默认选择器 |
| F-C04 | 考试详情/完成度 | P0 | 管、级、班（按范围）、科（本科） | 查看科目配置；按班级×科目展示已录/缺考/未录；关联导入批次；快速跳到导入；任课老师只看本科完成度 |
| F-C05 | 删除考试 | P0 | 管 | 仅无任何成绩时可删除；否则只能归档；删除需二次确认 |
| F-C06 | 历史考试支持 | P0 | 管、级、班 | 可为历史学期创建/确认考试并走同一导入流程；历史班级需映射到稳定班级组；趋势按考试日期排序；历史考试与当前考试同一套口径 |
| F-C07 | 考试合并/重命名 | P1 | 管、级 | 检测同名/近似考试；合并重复考试的成绩与批次；合并前预览冲突；写审计；合并后重算汇总 |

## 5. 成绩导入

| ID | 功能 | 优先级 | 角色 | 验收要点 |
| --- | --- | --- | --- | --- |
| F-D01 | 标准模板下载 | P0 | 有导入权限者 | 提供整班宽表、单科表、学生名单三种模板；含填写说明与示例；格式为 `.xlsx` |
| F-D02 | 上传与解析 | P0 | 有导入权限者 | 支持 `.xlsx` / `.xls` / `.csv`；≤ 10MB、≤ 5,000 行；自动定位表头；显示 sheet/行数/列数/前 10 行预览；加密文件/宏文件拒绝并提示 |
| F-D03 | 手动/规则表头映射 | P0 | 有导入权限者 | 学号、姓名、科目列可逐列指定；支持"跳过此列"；同义词自动建议；未完成必填映射不能下一步 |
| F-D04 | AI 表头映射 | P1 | 有导入权限者 | 规则/模板未覆盖时调用；只发表头+3 行脱敏样例；返回列映射/考试元信息/置信度；低置信度高亮；超时/失败自动转手动 |
| F-D05 | 映射模板复用 | P1 | 有导入权限者 | 成功入库后按表头指纹保存模板；同格式自动套用并标注"模板命中"；管理员可停用/删除（P2） |
| F-D06 | 数据校验 | P0 | 有导入权限者 | 校验学号存在/重复、分数范围、缺考、总分对账、行数、班级匹配；错误必须修正；警告需确认；可原地修改或标记缺考/跳过 |
| F-D07 | 提交入库 | P0 | 管、级、班 | 事务写入；选择或创建考试与科目配置（考试缺失时由管/级/班创建，按名称查重）；写成绩与变更日志；重建汇总；重复提交幂等；失败整体回滚 |
| F-D08 | 导入历史 | P0 | 有导入权限者 | 按时间/操作人/考试/状态筛选；显示文件名、考试、操作人、时间、结果统计；只能看权限范围内批次 |
| F-D09 | 导入详情/映射快照 | P0 | 有导入权限者 | 查看原始文件名、解析行数、映射、校验报告、错误明细；授权下载原始文件；可复制映射用于排查 |
| F-D10 | 撤销导入 | P1 | 管、级、班（本班/本年级） | 入库后 24 小时内可撤销；按变更日志恢复；若后续有改动同一单元格则拒绝并列出冲突；撤销后重算汇总并审计 |
| F-D11 | 单科导入/合并 | P1 | 管、级、班 | 选择已有考试+科目；只导入本科成绩；与已有单科成绩按策略合并；不影响其他科目；用于代任课老师汇总单科表 |
| F-D12 | 重复导入策略 | P1 | 管、级（覆盖需权限） | 支持拒绝（默认）/只补缺失/覆盖；覆盖需明确确认并写变更日志；策略随批次记录 |
| F-D13 | 成绩更正 | P1 | 管、级、班（按范围） | 单科单值修改；必须填写原因；校验范围；写审计；重算汇总与排名；任课老师默认只读 |
| F-D14 | AI 状态与降级 | P1 | 管（设置）、全部（提示） | 设置页显示 AI 开关/模型/连通状态；失败时导入页明确提示并切换手动映射；不阻塞导入 |
| F-D15 | 多 sheet 导入 | P2 | 有导入权限者 | 支持一班一表/一科一表；每个 sheet 独立映射；作为同一批次组提交 |
| F-D16 | 导入草稿 | P2 | 有导入权限者 | 保存解析/映射进度；可稍后继续；草稿过期清理策略明确 |

> 首版"有导入权限者"指管理员、年级主任、班主任；任课老师默认只读。原型中任课老师导入数学的交互仅作示意，实施时按本权限矩阵执行。

### 导入校验规则摘要

| 规则 | 级别 | 处理 |
| --- | --- | --- |
| 缺少学号/姓名/科目列 | error | 阻止 |
| 学号不存在 | error | 列出并允许跳过/先建档 |
| 文件内学号重复 | error | 阻止，提示合并或删除 |
| 分数非数字且非缺考标记 | error | 阻止，定位行/列 |
| 分数 < 0 或 > 满分 | error | 阻止，修正或标记缺考 |
| 正常成绩为空 | error | 阻止，补录或标记缺考 |
| 缺考标记同时有分数 | error | 阻止 |
| 同考试同科目已有成绩且策略=拒绝 | error | 阻止，切换策略需权限 |
| 总分列与各科之和不一致（> 1 分） | warning | 确认后继续；总分列不入库 |
| 姓名/班级与系统不一致 | warning | 确认后继续 |
| 合并单元格/公式无缓存值 | warning | 定位并要求确认/修正 |
| 排名/备注等列被忽略 | info | 展示即可 |

规则细节与实现见《项目架构》5.6。

## 6. 分析与看板

| ID | 功能 | 优先级 | 角色 | 验收要点 |
| --- | --- | --- | --- | --- |
| F-E01 | 全局考试/班级筛选 | P0 | 全部 | 顶栏选择考试（默认当前学期最近一场）与班级（按范围）；任课老师额外带科目上下文（默认所教科目）；筛选写入 URL；切换后各卡片一致更新 |
| F-E02 | 班级 KPI | P0 | 管、级、班；科为单科 KPI | 总分平均分、总分及格率、总分优秀率、参考人数/完整人数；显示与上次考试、年级均值的对比；缺考人数标注。任课老师只显示本科平均分/及格率/优秀率/参考人数，不显示总分与总分排名 |
| F-E03 | 各科平均分对比 | P0 | 全部（按范围） | 本班 vs 年级各科平均分柱状图；显示满分与及格线；科目顺序与配置一致；任课老师只显示本科 |
| F-E04 | 历次考试总分趋势 | P1 | 全部（按范围） | 按班级组串联同一班级在不同学期的考试，展示总分平均分与年级均值；缺数据点跳过并标注；支持选择学期范围；任课老师只看本科趋势 |
| F-E05 | 学生排名表 | P0 | 全部（按范围） | 总分、各科、班级/年级排名、名次变化；按总分排序；分页；点击进入学生档案；缺考行标注且不参与排名。任课老师只显示本科成绩与单科排名 |
| F-E06 | 分数段分布 | P1 | 全部（按范围） | 可选科目或总分；单科 10 分一段、总分 50 分一段；显示人数与占比；缺考不计入 |
| F-E07 | 临界生提醒 | P1 | 班、级、管、科（本科） | 单科成绩距及格线/优秀线 ±5 分（可配）；列出学生、目标线、当前分、差距；点击进入档案；任课老师只显示本科 |
| F-E08 | 年级对比 | P1 | 级、管 | 各班总分平均分对比；学科贡献热力表（班级单科得分率 − 年级单科得分率，百分点）；颜色阈值可配 |
| F-E09 | 学生档案 | P1 | 全部（按范围） | 基本信息、本次总分/班排/年排/变化；各科成绩与优势/偏科标签（z 分数）；多科雷达图（各科按满分轴 + 班级均值）；历次名次趋势（按 student_id 跨学期串联）；考试历史列表。任课老师不显示多科雷达/总分，仅显示本科成绩、单科排名与本科趋势 |
| F-E10 | 学生列表/搜索 | P1 | 全部（按范围） | 按姓名/学号搜索；按班级筛选；分页；结果受数据范围限制 |
| F-E11 | 两次考试对比 | P2 | 全部（按范围） | 选择两次考试，对比总分/各科/排名变化；处理缺考与科目差异 |
| F-E12 | 科目筛选分析 | P2 | 全部（按范围） | 可选择部分科目查看图表；明确标注"探索视图，非官方总分"；官方总分仍按考试配置 |
| F-E13 | 导出 | P1 | 全部（按范围） | 排名表/年级对比导出 `.xlsx`；图表导出 PNG；文件名含考试/班级/日期；导出遵循权限 |
| F-E14 | 打印视图 | P2 | 全部（按范围） | 看板/学生档案提供打印友好布局；隐藏导航与操作按钮 |
| F-E15 | 口径说明 | P0 | 全部 | 每个指标有 tooltip 或说明；缺考/并列/参考人数口径可查；避免"数字对不上"的争议 |

> 任课老师进入看板/档案时使用"单科模式"：只展示本科目的均分、及格/优秀率、分布、单科排名和该生本科成绩，不展示总分、总分排名及其他科目；API 按科目裁剪，而非仅前端隐藏。

### 关键指标口径

| 指标 | 定义 |
| --- | --- |
| 总分 | 所有"计入总分"科目成绩之和；总分满分 = 各科目配置满分之和；缺考科目者不计算总分 |
| 总分平均分 | 完整参考学生的总分平均；不完整学生不参与 |
| 总分及格率/优秀率 | 总分 ≥ 总分满分 × 60% / 80% 的完整参考学生占比 |
| 单科平均分/率 | 分母为该科有有效成绩的学生；缺考剔除 |
| 参考人数 | 至少一科有有效成绩的学生数 |
| 完整参考人数 | 所有计入总分科目均有有效成绩的学生数 |
| 班级/年级排名 | 完整参考学生按总分降序，同分同名次、下一名跳号 |
| 名次变化 | 该生上一场有完整成绩的考试名次 − 本次名次；跨学期按 student_id 关联；正数为进步；无数据显示"—" |
| 分数段 | 单科默认 10 分一段；总分默认 50 分一段 |
| 标准分 z | `(成绩 − 均值) / 标准差`，默认按班级；z ≤ −1.5 偏科，z ≥ +1.5 优势 |
| 学科偏差 | 班级单科平均得分率 − 年级单科平均得分率（百分点） |
| 临界生 | 单科距及格线或优秀线 ±5 分以内 |
| 显示精度 | 成绩 2 位小数；平均分/率 1 位小数；排名整数 |

> 班级趋势按稳定班级组（`class_group`）串联，学生趋势按 student_id 串联；跨学期不依赖学期内的 class_id。
>
> 及格/优秀比例默认 **60% / 80%**，按各科配置的满分计算；各科满分可按地区/考试设置。撤销窗口默认 24 小时。修改比例后需重算受影响的考试汇总。原型中的"优秀线 85%"为设计示例，以实现默认 80% 为准。
>
> "单科满分"指该科卷面总分；"考试总分满分"为各计入科目单科满分之和，不固定为 750/800。

## 10. 发布计划

### M0：可运行的主链路（P0）

- 登录/退出、角色与数据范围、教师与任课分配。
- 学期/年级/班级/学生/科目基础数据 + 学生名单导入。
- 考试记录随导入创建：在导入向导中确认学期/年级/名称/类型/日期与科目满分。
- 整班宽表导入：上传 → 手动/规则映射 → 校验 → 事务入库 → 导入历史。
- 班级看板：KPI、各科均分对比、学生排名表。
- 种子数据与本地 SQLite 数据库文件（`apps/api/data/scorelens.db`）。

**验收**：管理员配置好学期/班级/学生 → 班主任导入一场期中考试并创建考试记录 → 班主任登录看到正确的平均分、及格率、排名；所有数字可与原表抽样核对，每科满分与及格/优秀线按配置计算。

### M1：完整体验（P1）

- AI 表头映射 + 映射模板；单科导入与合并；重复导入策略；考试合并/重命名。
- 撤销导入、成绩更正、审计日志。
- 历次趋势、分数段、临界生、年级对比、学生档案、学生搜索。
- Excel/PNG 导出；统计口径设置；AI 设置。
- 性能优化与缓存验收。

**验收**：三种不同格式的表格（整班宽表、单科表、WPS 导出）均可完成导入；导入后可撤销并恢复原值；切页无空白等待。

### M2：增强与硬化（P2 + 部署）

- 多 sheet 导入、两次考试对比、科目筛选分析、打印视图。
- 备份状态/手动备份、数据归档、系统健康页、通知中心。
- 安全加固、备份恢复演练、Ubuntu 24.04 测试环境验收与正式部署准备。
- 历史成绩批量回溯与数据核对。

## 11. 首版不做

- 学生端/家长端成绩查询。
- 在线阅卷、答题卡识别、自动判分。
- 排课、教务考试编排、考勤、学籍系统对接；首版只做成绩导入与可视化。
- 体育、实验操作、会考等级转换的完整口径（仅预留科目配置）。
- 多校 SaaS/多租户。
- 移动 App/小程序。
- 即时通讯、短信通知。
- AI 自动生成整表数据或自动改分。

## 12. 待确认事项

1. 个别科目是否需要不同的及格/优秀比例（当前统一 60% / 80%；各科满分按考试配置）。
2. 免考/缓考是否需要独立状态（当前只有"缺考"，且剔除总分排名）。
3. 导入时创建考试可能产生同名/近名重复记录，合并规则与审批人需明确。
4. 任课老师是否需要单科导入/更正权限（当前默认只读，由班主任/年级主任导入）。
5. 学生名单由学籍系统导出还是手工维护，更新频率如何。
6. 历史成绩覆盖哪些学年、表格格式是否统一、是否有缺失。
7. 地理/生物会考、体育、实验操作是否需要作为"仅展示不计总分"的科目类别。
8. 正式生产部署环境（测试环境已定为 Ubuntu 24.04）与是否校外访问。
9. AI 服务商选择与密钥管理方式（环境变量 or 管理界面加密存储）。
10. 导出文件是否需要水印/导出审计（涉及学生信息外带）。
